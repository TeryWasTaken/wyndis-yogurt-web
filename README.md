Wyndi's Yogurt Website: 
Website satu halaman untuk Wyndi's Yogurt, yogurt ramah lambung yang dibuat dengan fermentasi tradisional secara manual sejak 2016. Website ini memperkenalkan brand, produk, dan kontak.

Anggota Kelompok:

b. Anuari Al Adhan (adhannanuari), 
c. Dhafa Irwansyah (dhafa0712), 
d. Satria Farhan Lutfian (PoloBlanca).

Latar Belakang: 
Project ini dibuat sebagai tugas kelompok untuk membangun website promosi Wyndi's Yogurt. Pengerjaan dibagi menjadi 4 bagian yang dikerjakan berurutan, memakai alur kerja GitHub (branch, commit, pull request) agar setiap anggota melanjutkan pekerjaan anggota sebelumnya.

Fitur / Section: 
a. Home: cover dengan maskot dan tagline.
b. Menu navigasi: menu atas yang ikut aktif saat scroll, serta menu samping dengan tautan ke tiap section.
c. About Us: cerita singkat dan keunggulan Wyndi's Yogurt.
d. Our Products: carousel produk yang bisa digeser atau diklik.
e. Detail Produk: Ice Cream Yogurt, Greek Style Yogurt, Regular Yogurt Drink, dan Yogurt Blend.
f. Contact Us: tautan Instagram dan WhatsApp.
g. Tampilan yang bisa menyesuaikan ukuran layar.

Teknologi yang Digunakan: 
a. HTML5, 
b. CSS3, 
c. JavaScript (tanpa framework), 
d. Google Fonts (Poppins), 
e. Git dan GitHub (GitHub Pages untuk hosting), 

Cara Menjalankan Website Secara Lokal: 
a. Clone repo, 
b. Masuk ke foldernya, 
c. Buka index.html di browser. 
Notes: Tidak perlu instalasi tambahan. Koneksi internet hanya dibutuhkan untuk memuat font Poppins.
